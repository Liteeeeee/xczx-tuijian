## 二、🔴 必改项（否则跑不通 / 审核必拒）

### 2.1 填入真实 AppID & 开启 URL 检查

修改 `src/manifest.json`：

```json
{
  "mp-weixin": {
    "appid": "wxXXXXXXXXXXXX",        // ⚠️ 替换为真实 AppID
    "setting": {
      "urlCheck": true,               // ⚠️ 发布前必须改回 true，否则上传时报错
      "es6": true,
      "enhance": true,
      "postcss": true,
      "minified": true
    }
  }
}
```

### 2.2 生产环境注入真实 API 域名

小程序端**没有 Vite 代理**，所有 `/app`、`/app-api` 路径必须直接拼上真实 HTTPS 域名。

#### 方式 A：环境变量注入（推荐，不侵入代码）

```bash
# 生产打包（Linux / macOS）
VITE_API_BASE_URL=https://api.xiancaozhenxuan.com npm run build:mp-weixin

# 生产打包（Windows PowerShell）
$env:VITE_API_BASE_URL="https://api.xiancaozhenxuan.com"; npm run build:mp-weixin
```

#### 方式 B：写死到 `request.js`（不推荐，仅作为 fallback）

`src/utils/request.js` → `resolveBaseUrl()` 兜底判断是否小程序端：

```js
function resolveBaseUrl() {
  // #ifdef MP-WEIXIN
  return 'https://api.xiancaozhenxuan.com';   // ⚠️ 替换
  // #endif
  try {
    const userVite = typeof __API_BASE_URL__ === 'string' ? __API_BASE_URL__ : '';
    if (userVite) return userVite.replace(/\/+$/, '');
  } catch (ignore) {}
  return '';
}
```

### 2.3 配置微信公众平台「服务器域名」

登录 https://mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名：

| 配置项 | 示例值（替换为真实域名） |
| :--- | :--- |
| request 合法域名 | `https://api.xiancaozhenxuan.com` |
| downloadFile 合法域名 | `https://xcai-test.oss-cn-hangzhou.aliyuncs.com` |
| uploadFile 合法域名 | （如有上传头像/图片需求时填） |
| socket 合法域名 | （如有 WebSocket 时填） |

> ⚠️ 域名必须**已备案 + 走 HTTPS + 通配符只能用一级**，不能写 IP、不能写 `localhost`、不能带端口号。

### 2.4 首次启动必弹「用户隐私保护指引」弹窗

微信 2023 年 9 月起**强制**：小程序首次启动必须显式弹《用户隐私保护指引》并用户**主动同意**后，才能调用 `uni.login` / `getPhoneNumber` / 上传设备信息 / 获取定位等敏感 API，否则审核 100% 拒。

**必须实现的逻辑**（推荐放 `App.vue` onLaunch）：

```js
// App.vue onLaunch 内
const sysInfo = uni.getSystemInfoSync();
const SDKVersion = sysInfo.SDKVersion || '0.0.0';
if (uni.getPrivacySetting && compareVersion(SDKVersion, '2.32.3') >= 0) {
  wx.getPrivacySetting({
    success(res) {
      if (res.needAuthorization) {
        // 唤起官方隐私弹窗（需要页面中有 <button open-type="agreePrivacyAuthorization">同意</button>）
        // 或者使用 wx.requirePrivacyAuthorize({ success, fail })
      }
    }
  });
}

function compareVersion(v1, v2) {
  v1 = v1.split('.'); v2 = v2.split('.');
  const len = Math.max(v1.length, v2.length);
  while (v1.length < len) v1.push('0');
  while (v2.length < len) v2.push('0');
  for (let i = 0; i < len; i++) {
    const n1 = parseInt(v1[i]), n2 = parseInt(v2[i]);
    if (n1 > n2) return 1;
    if (n1 < n2) return -1;
  }
  return 0;
}
```

同时，必须在 mp.weixin.qq.com「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」中同步填写好对应功能的隐私声明。

### 2.5 确认 TabBar 图标文件存在

检查 `static/` 下这 6 张图：

```
static/tabbar-home.png            (首页 未选中)
static/tabbar-home-active.png     (首页 选中)
static/tabbar-combo.png           (营养组合 未选中)
```

## 三、🟡 高优（影响体验 / 容易踩坑）

### 3.1 静态资源压缩（2MB 单包限制）

微信小程序**单包大小 ≤ 2MB**（分包总大小 ≤ 20MB）。本项目所有图片都在 `static/`，打包后会被完整复制进包体。

**检查 & 压缩步骤：**

```bash
# 1. 先打包一次看看体积
npm run build:mp-weixin
du -sh dist/build/mp-weixin      # 如果 > 2MB 必须压缩

# 2. 重点压缩的图片
static/images/登录_slices/pagebackground.png     # 登录页全屏背景 → 转 WebP / 压到 200KB 内
static/images/推荐 demo 首页切图/Group 8@2x.png  # 轮播兜底图 → 压到 100KB 内
static/images/range/*.png                         # 6 张年龄 icon → 整体控制在 100KB 内
```

**如果打包后仍 > 2MB**：
- 大图上 OSS 走远程 `<image src="https://...">`（downloadFile 白名单中加好域名）
- 或者使用 uni-app**分包加载**（subPackages）：把 `pages/recommend/*`、`pages/user/*` 设为分包，`pages/index/*`、`pages/combo/*` 放主包

### 3.2 自定义 TabBar 真机校验

我们使用了 `uni.hideTabBar()` + `src/components/custom-tab-bar/custom-tab-bar.vue` 自定义 TabBar，来严格控制图标 20×24px。

**真机必须验证 3 点：**
1. **底部不会跳动**：每次切换 Tab 都能正确隐藏原生、显示自定义
2. **高亮状态**：切 Tab 时对应 tab 的 active icon + 主题色文字正确切换
3. **不遮挡内容**：所有 Tab 页底部都留够了 `padding-bottom: 140rpx` + `env(safe-area-inset-bottom)`

> 👉 重点测 iPhone 12/13/14 Pro（顶部灵动岛）和 iPhone SE（小屏）。

### 3.3 样式兼容性

| CSS 特性 | 小程序表现 | 处理 |
| :--- | :--- | :--- |
| `backdrop-filter: blur()` | iOS 支持，Android 低版本不支持 | 历史记录卡片毛玻璃、Loading 遮罩，Android 降级方案是半透明白底 `rgba(255,255,255,0.72)` 不写 filter |
| `position: fixed` 多层嵌套 | 小程序在某些容器内 fixed 会失效 | Loading 遮罩应写在页面根节点最外层，不要嵌套在滚动容器里 |
| 通配符 `* {}` | 小程序禁止 | 全局 reset 写在 `App.vue` 的根样式中 |
| GIF 动画 | 支持，但体积大建议别用太大 | 当前 `loading.gif` 建议控制在 500KB 内 |

### 3.4 API 兼容（DOM / BOM 禁用）

小程序端**没有 `window`、`document`、`location`**。任何用到 DOM 的代码必须做条件隔离：

```js
// ✅ 正确：当前 request.js 已做
try {
  if (typeof window !== 'undefined') console.log('[request]', ...);
} catch (ignore) {}

// ❌ 禁止：直接写 document.querySelector / window.location.href / new Image()
```

### 3.5 登录流程 & 审核合规

微信小程序审核**严禁强制登录**：
- ✅ 正确：首页、营养组合页未登录也能浏览
- ✅ 正确：点击「开始推荐」或「我的」时才引导登录
- ❌ 禁止：首页一进就弹登录框，审核直接拒

如果后续加**微信一键登录 / 获取手机号**：
- 必须用 `<button open-type="getPhoneNumber">`，不能自定义按钮
- 必须在**用户点击之后**才能触发，不能页面加载就调
- 必须已经弹出过「用户隐私保护指引」并确认用户同意

## 四、🟢 优化 & 体验

### 4.1 分享配置（onShareAppMessage）

首页和推荐结果页**强烈建议**加上分享入口，否则右上角「发送给朋友」是灰色默认封面（没有吸引力）：

```js
// pages/index/index.vue / pages/recommend/result.vue
import { onShareAppMessage, onShareTimeline } from '@dcloudio/uni-app';

onShareAppMessage(() => ({
  title: '仙草甄选AI面包推荐：根据你的口味定制专属配方',
  path: '/pages/index/index',
  imageUrl: '/static/share-cover.png'   // 建议 500×400px，5:4 比例
}));

onShareTimeline(() => ({
  title: 'AI 面包推荐 · 仙草甄选',
  imageUrl: '/static/share-cover.png',
  query: ''
}));
```

### 4.2 图片懒加载 & 兜底

已经在首页轮播、商品卡片等处用了 `@error` 替换本地兜底图，保持即可。小程序 `<image>` 组件建议加 `lazy-load` 属性优化长列表：

```html
<image lazy-load mode="aspectFill" :src="picUrl" @error="onError" />
```

### 4.3 Pinia 纯内存状态 & 小程序生命周期

我们坚持了「业务数据走纯内存 Pinia、Token 走持久化 Storage」的架构。小程序端需要注意：
- 切 Tab / navigateBack 不会销毁 App 实例，Pinia 状态会保留
- 如果冷启动后需要恢复「我的」页面用户信息，只需要**从 Storage 拿 Token 调一次接口拿用户信息写回 Pinia**即可
- **不要在 Pinia 中 use(persist 插件)**，保持当前纯内存方式避免脏数据串号

## 五、打包 & 发布流程

### 5.1 生产打包

```bash
# 安装依赖（如果第一次或 package.json 有变更）
npm install

# 打包小程序（注入真实 API 域名）
VITE_API_BASE_URL=https://api.xiancaozhenxuan.com npm run build:mp-weixin
```

打包产物位置：`dist/build/mp-weixin`

### 5.2 微信开发者工具导入

1. 下载并安装「微信开发者工具」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开工具 → 「导入项目」
   - 项目目录：选择 `dist/build/mp-weixin`
   - AppID：填入真实 `wxXXXXXXXXXXXX`（不要用测试号，正式发布必须真实 AppID）
   - 项目名称：仙草甄选 AI 推荐
3. 点「编译」，看控制台是否有红色报错
4. 点「预览」→ 用手机扫码，**真机上从头到尾跑一遍完整流程**：

> 🔴 **真机必测清单**：
> - [ ] 首页轮播图正常显示（接口通 + 图片加载无死链）
> - [ ] 点击「智能推荐」能正确进入问卷页
> - [ ] 年龄范围 3 列卡片 + 其他选项橙金渐变选中态正常
> - [ ] 提交表单 → Loading 遮罩 + GIF + 文案正确显示（不重复点击）
> - [ ] 结果页商品 2 列网格正常渲染
> - [ ] 底部「返回首页」沉底按钮点击正确跳转
> - [ ] 我的页面 → 登录页 → 手机验证码登录全流程跑通
> - [ ] 底部 TabBar 3 个页面切换高亮正确、不遮挡内容
> - [ ] iPhone 底部小黑条安全区适配 OK

### 5.3 上传版本

真机确认无 Bug 后：
1. 开发者工具右上角「上传」按钮
2. 填写版本号（和 `manifest.json` 保持一致，如 `0.1.0`）+ 项目备注（如"小程序首发版本，支持 AI 问卷推荐、历史记录"）
3. 等待上传完成

### 5.4 提交审核

登录 https://mp.weixin.qq.com → 版本管理 → 开发版本 → 找到刚上传的版本 → 「提交审核」：

| 字段 | 填写示例 |
| :--- | :--- |
| 功能页面 | `pages/index/index`（首页）、`pages/combo/index`（营养组合）、`pages/recommend/question`（推荐问卷）、`pages/user/index`（我的）、`pages/user/login`（登录） |
| 功能标签 | 生活服务 / 电商 · 食品 / AI 辅助工具 |
| 测试账号 | 填一个审核员可用的手机号（最好是真实可收验证码的） |
| 测试备注 | 「首页 → 智能推荐 → 填任意选项 → 提交即可看到推荐结果；我的 → 点击头像 → 输入任意手机号 + 验证码 123456 可登录」 |
| 隐私说明 | 「收集手机号：用于注册登录；收集用户填写的问卷选项：用于生成个性化面包营养推荐，不会用于其他用途」 |

审核时间通常 1~2 个工作日，如果驳回按驳回理由修即可。

### 5.5 审核通过 → 发布

版本管理 → 审核版本 → 「发布」→ 全量发布。发布后用户在微信小程序搜索「仙草甄选AI推荐」就能搜到了。
